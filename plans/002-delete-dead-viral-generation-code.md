## Why this matters

`packages/generation/src/viral-prompt.ts` (~127 lines) and
`packages/generation/src/viral-generation.ts` (~240 lines) are exported from
the package but imported by nothing in any app or other package. They encode a
2022-era "viral content strategist" prompting style — hook formulas like
"Unpopular opinion:", "Hot take:", and CONTENT_STYLE/FORMAT_STYLE menus — that
the June 2026 prompt rewrite deliberately removed; the live pipeline now
hard-rejects those very phrases via `GENERIC_SLOP_PATTERNS` in
`packages/generation/src/index.ts`. Keeping two contradictory prompt systems in
one package invites someone (or some agent) to wire the wrong one in.
